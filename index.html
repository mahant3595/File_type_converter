Run it locally

Node.js 20+. The conversion engines are server-side, so a static host alone won’t run them — deploy to any Node host.

# clone and install
git clone https://github.com/mahant3595/File_type_converter.git
cd File_type_converter
npm ci

# development (http://localhost:3000)
npm run dev

# tests, lint, production
npm test
npm run lint
npm run build && npm start
